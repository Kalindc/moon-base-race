# Game art

The cutscene videos (`.mp4`) and pictures (`.jpg`) the game shows. They are AI-generated with Higgsfield: artist's impressions, not photographs. `scenario.json` points at these files by name, and if a file is missing the game shows its drawn placeholder scene instead.

## How the files get here

The maintainer stores the private download links in a repository secret named `ART_MANIFEST` (Settings, then Secrets and variables, then Actions), then runs the **Fetch game art** workflow from the Actions tab. It downloads every file into this folder and shrinks it for the web with `tools/compress_art.py`. Contributors can also add a file here directly, named exactly as listed below.
